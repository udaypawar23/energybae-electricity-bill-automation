# Energybae Electricity Bill Automation

## Project Overview
This project automates electricity bill data extraction and fills the solar load Excel template automatically.

The system:
- Uploads electricity bill PDF/image
- Extracts important data using OCR
- Fills Excel template automatically
- Generates ready-to-use solar load output

## Technologies Used
- Python
- Streamlit
- OCR (Tesseract)
- pdfplumber
- openpyxl
- pandas

## Features
- PDF and image support
- Automatic data extraction
- Excel automation
- Formula-safe Excel filling
- Download filled Excel output
